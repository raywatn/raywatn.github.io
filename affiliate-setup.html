PARTNER CONFIGURATION

Make every search
trackable.

This setup page prepares your Awin tracking configuration. It does not connect to Awin or create commissions by itself. First, your publisher account must be approved and you must be accepted into each advertiser programme.

Before approval: leave these fields empty. The public site will use standard Google Travel search links and clearly tell visitors that affiliate tracking is not active yet.

Step 1 — Apply to Awin

Register as a Publisher and use your live FlyStay website URL as the Promotional Space URL. If the site is not published yet, publish it first using GitHub Pages or Cloudflare Pages.

Open Awin Publisher Signup ↗

Awin asks publishers for a promotional space such as a website or social channel. Payment/tax details are required before receiving payments. Any signup deposit or verification amount, if shown for your region, will be displayed in Awin's own form; check it before paying.

Step 2 — After Awin approves you

Join a travel advertiser programme in Awin. Copy your Publisher ID and that advertiser's Advertiser ID (MID). Ask the advertiser or Awin for a supported flight/hotel search landing URL format that accepts destination and dates.

Use the exact URL pattern supplied/approved by the flight advertiser. Placeholders: {origin}, {destination}, {depart}, {return}.

Use the exact URL pattern supplied/approved by the hotel advertiser. Placeholders: {destination}, {checkin}, {checkout}, {guests}.

Step 3 — Copy these settings into config.js

Replace the matching settings in the website's config.js file with the generated values, save, and upload the updated file to your website.



Important
Awin's standard deeplink structure uses your Publisher ID, the advertiser's MID and an encoded destination URL. Some advertisers do not allow deeplinking or require specific search URL formats. The link will only track if the advertiser programme is approved and its terms permit your promotional method.
